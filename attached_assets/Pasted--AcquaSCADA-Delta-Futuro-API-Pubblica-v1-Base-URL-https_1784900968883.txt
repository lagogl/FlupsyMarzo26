2. Storico misure
GET /api/public/v1/history?parameter=<param>&from=<ISO8601>&to=<ISO8601>&limit=<n>

Parametro query	Obbligatorio	Default
parameter	✅	—
from	no	inizio storico
to	no	adesso
limit	no	1000 (max 5000)
Valori validi per parameter:

Valore	Grandezza	Unità
o2sat	Saturazione O₂ vivaio (ID 70)	%
o2mgl	Ossigeno disciolto vivaio (ID 70)	mg/L
o2temp	Temperatura vivaio (ID 70)	°C
p71sat	Saturazione O₂ Flupsy (ID 71)	%
p71mgl	Ossigeno disciolto Flupsy (ID 71)	mg/L
p71temp	Temperatura Flupsy (ID 71)	°C
p72nh3	Ammoniaca NH₃ (ID 72)	mg/L
p72ph	pH (ID 72)	pH
p72temp	Temperatura SEN0711 (ID 72)	°C
vasca	Livello vasca idrovore	cm
laguna	Livello laguna	cm
Esempio:

GET /api/public/v1/history?parameter=p72nh3&from=2026-07-01T00:00:00Z&limit=500

Risposta:

{
  "parameter": "p72nh3",
  "description": "Ammoniaca NH3 sonda SEN0711 (ID 72)",
  "unit": "mg/L",
  "from": "2026-07-01T00:00:00.000Z",
  "to": null,
  "count": 142,
  "readings": [
    { "recordedAt": "2026-07-01T06:00:00Z", "value": 0.038 },
    ...
  ]
}

Note tecniche
Le date sono sempre in ISO 8601 UTC
Il dato viene aggiornato circa ogni 30 secondi (frequenza di polling del bridge)
Se status = "offline" per più di qualche minuto, il bridge locale (PC di valle) potrebbe essere spento o non connesso a internet
